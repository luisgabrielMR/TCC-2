# Scripts de apoio

Os scripts automatizam tarefas repetitivas: preparar banco, gerar payloads,
validar APIs, executar uma linguagem e consolidar resultados. Normalmente,
quem está começando deve usar os atalhos em `../launchers/`.

Os scripts não são uma lista de comandos para executar aleatoriamente. Alguns
alteram o banco, outros iniciam containers e outros apenas leem resultados.
Use a documentação técnica para saber a finalidade de cada grupo.

Veja [TECHNICAL.md](TECHNICAL.md) para o mapa de scripts e as distinções entre
preparação, validação, piloto e execução oficial.
