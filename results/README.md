# Resultados

Os resultados de cada execução ficam em arquivos, não apenas no dashboard.
Isso permite verificar depois o que foi medido e como cada número foi obtido.

- `raw/`: arquivos completos de cada execução.
- `processed/`: tabelas consolidadas.
- `summaries/`: relatórios e dashboard HTML.
- `archive/`: resultados históricos preservados, fora da comparação atual.

Uma execução piloto é marcada `non_official`. A campanha oficial usa
`official`. Não altere nomes ou copie arquivos para promover um piloto: a
classificação, o fingerprint da campanha e o protocolo fazem parte da
evidência.

Veja os arquivos e os filtros em [TECHNICAL.md](TECHNICAL.md).
