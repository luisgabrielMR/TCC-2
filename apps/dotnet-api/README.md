# .NET API

Implementacao planejada para etapa posterior.

Diretrizes:

- ASP.NET Core Minimal API com Npgsql direto.
- Pool configurado explicitamente pelas variaveis `DB_POOL_*`.
- Sem Entity Framework, scaffolding automatico ou MVC complexo.
- Endpoint externo padrao durante testes: `http://localhost:8000`.
