PRE-REQUISITO
1. Abrir o Docker Desktop manualmente.
2. Aguardar aparecer Docker Engine running.
3. Nao iniciar bateria se outra API estiver usando a porta 8000.

VERIFICAR O PROJETO
1. Duplo clique em 14_VERIFICAR_PROJETO_COMPLETO.bat.
2. A verificacao reseta apenas benchmark_db e nao cria resultado oficial.
3. Ao final, conferir a pasta mais recente em results/raw/verification/<data-hora>/, principalmente preflight.json e monitoring-preflight.json.

TESTE PILOTO
1. Duplo clique em 07 a 11 para uma linguagem, ou 12 para todas.
2. Esses atalhos usam controlled_50 e sao marcados non_official.
3. Para carga extra, usar 16 (100 usuarios) ou 17 (200 usuarios); continuam pilotos.

BATERIA OFICIAL
1. Revisar e versionar todas as mudancas; git status deve estar limpo.
2. Instalar manualmente Docker Engine 29.5.2 e Docker Compose 5.1.4.
3. Garantir que cAdvisor publique CPU e memoria da API, PostgreSQL e Locust.
4. Executar novamente 14_VERIFICAR_PROJETO_COMPLETO.bat nesse ambiente e no commit limpo.
5. Duplo clique em 18_BATERIA_50_100_200.bat.
6. O atalho executa 3 repeticoes, perfis 50/100/200 e rotacao da ordem.
7. Qualquer divergencia de ambiente, Git, comprovante de verificacao ou cAdvisor bloqueia a bateria.

RESUMOS E GRAFICOS
1. Duplo clique em 13_RESUMIR_RESULTADOS.bat.
2. Duplo clique em 15_GERAR_GRAFICOS.bat para o painel HTML.
3. Duplo clique em 19_ABRIR_GRAFANA.bat para os dois dashboards.
4. Resultados Oficiais mostra somente classification=official.
5. Monitoramento e Diagnostico filtra linguagem, endpoint, cenario, perfil, metodologia e rodada.

CRITERIOS DE UMA RODADA OFICIAL
- preflight sem bloqueios;
- project-verification.json corresponde ao mesmo commit limpo;
- Git limpo e commit registrado;
- contrato e estado final equivalentes nas cinco APIs;
- aquecimento de 300 segundos estavel;
- janela principal exata, sem aquecimento;
- cAdvisor validado para API, PostgreSQL e Locust;
- postgres-exporter e Prometheus saudaveis;
- zero falhas HTTP e tres repeticoes com ordem rotacionada.
